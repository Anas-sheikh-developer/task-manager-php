# Task Manager (PHP & MySQL)

A simple web application to manage daily tasks using core PHP, MySQL, and AJAX.

## Features
- User Authentication (Register, Login, Logout securely using PHP Sessions)
- Create, Read, Update, Delete (CRUD) Tasks
- Change Task Status (Pending, In Progress, Completed)
- Search and Filter Tasks
- View Task Statistics on Dashboard
- Responsive UI using Bootstrap 5

## Technologies Used
- PHP (Backend logic)
- MySQL (Database)
- HTML5, CSS3, Bootstrap 5 (Frontend)
- XAMPP (Local Server)
